# Reference

## motion-vocabulary.html

A working landing page where every scroll and animation technique is labeled
in place, with a toggle to hide the annotations and see it as a visitor would.
Built as a teaching tool: scroll it once with labels on, once with them off.

The glossary at the bottom names twelve techniques — scroll-reveal, stagger,
parallax, scroll-scrubbing, pinned sections, micro-interactions, page-load
sequence, count-up, condensing nav, marquee, easing, reduced motion — and gives
the exact phrase to use when asking for each one.

The brand is fictional ("Northline"); only the technique demonstrations matter.
